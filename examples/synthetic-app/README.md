# Synthetic example app

This directory holds a **completely fictional** app called "Sample
Tracker" so the layout and operation of the agent are visible without
revealing any real app's strategy.

**Nothing here is real:**

- The bundle id (`com.example.sampletracker`) uses the IANA-reserved
  `example.com` domain.
- The app id and version id are zero UUIDs.
- The release content is generic placeholder copy, not a real listing.
- The audit-trail entry is illustrative; there are no real Apple-side
  ids cited, and the operations described have not actually happened.

If you're a contributor, copy `fictional-app/` into a new folder under
`metadata/` and replace its contents with your own real data. Don't
commit real metadata files to this repo.
